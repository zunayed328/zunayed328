## Selected work

### Federated Self-Supervised Learning for Medical Image Classification
**Research · in progress · Python**  
Hospitals cannot pool imaging data, so models must learn across institutions without moving raw images. This project combines self-supervised pretraining with federated training to reduce the need for labelled data at each site. The repository currently holds the training configuration and source scaffold; experiments and results are not yet published.  
[Repository](https://github.com/zunayed328/Federated-Self-Supervised-Learning-for-Medical-Image-Classification-)
